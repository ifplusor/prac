# 轴二：认识论循环 + 决策交付单元（落到软件开发）

> 软件开发是创造性工作，没有重复的日常事务性内容。工作模式是「边做边想、不断调整」，很难在一开始把所有东西想清楚再开干。这决定了prac 的主模型是认识论循环，不是生产线。

## 为什么 agent 设计不好架构、爱走捷径

这**主要不是能力问题，是「框架」和「后果」问题**。agent 是**目标导向**的——忠实于「把这个任务完成」；而架构是一种**价值**（对未来的约束：为了以后能持续演进，现在宁可少做）。

在目标与价值冲突时，agent 会本能地**朝目标最省力的路径走**，因为价值没有被显式加载、也没有牙齿。只有当「架构的价值」被固化成一个带约束力的东西（决策历史、架构原则、必须过的测试门槛、不能破坏的既有决策），捷径才会真正失败，agent 才没法走。

现在的问题是：harness 给 agent 的「框架」是**当前任务**，不是**整个系统**。它从不把系统长期健康装进 agent 的视野，也从不曾让 agent「承担」自己决策的后果——每次调用都是全新头脑，昨天选的烂架构今天不会来追它。一个不需要与自己决策共存的执行者，当然没理由在乎架构。**这不是模型笨，是激励与报偿的框架错了。**

## 把「交付物」重新切开

关键：**agent 的单元是「决策」，不是「代码」；人的单元是「承诺」，不是「编辑」。**

软件开发的真正产物（有持续价值那部分）是**一套连贯、可维护的决策系统**——架构就是那些「做过一次、从此约束一切」的决策的压缩记录。代码只是这些决策的**执行残留**。

| | 产物 | 细述 |
| --- | --- | --- |
| **agent 的产物** | 候选决策 + 依据 + 验证证据 | 「有几个选项、各自代价、我推荐哪个、我打算怎么验证它」。代码只是副产品。 |
| **人的产物** | 把候选变成承诺的那份判断 + 系统的结构 | 那些幸存下来的约束。 |
| **软件项目的产物** | 一个能持续被演进的、真实运行的系统 | 包括未来的你。 |

现在的 agent 恰恰把「做出决策的空间」直接坍缩成了「改文件」——它给你看结果，不给你看它推理过的空间。于是你的「审查」被迫在**结果里找 bug**（贵、低杠杆），而不是在**决策层面**跟它对话（便宜、高杠杆）。你把控架构那么累，根因是 **agent 从不把它的决策过程当成一等公民交给你审**。

## 谁对最终结果负责

**软件里，人必须永远负责。** 因为软件是对世界（和对未来维护者、对你自己的未来）的一个**承诺**，agent 担不起。

但这里有个反转：

> **agent 不会从你手里「拿走」责任；一个设计好的 harness，是让「你的责任」变得可行使。**

责任不只是「锅在这」，而是「我能真正行使有效的判断」。一个把 agent 的**推理暴露、可验证、可回滚**的 harness，是在帮你把责任行使得又便宜又准。反之，长程自主的 harness 的危险在于：它让「把责任甩出去」在技术上变得太容易，造成责任**真空**——你以为有验证，其实没人真在看，信任膨胀到远超实际核验。

大疑虑：现在行业走向「long-horizon 自主」，可能是在为一种和你不一样的工作优化。

## 你工作的本质是认识论循环，不是生产线

你说「边做边想、很难一开始想清楚」——这条特别关键，而且**与大多数 harness 的结构（先立计划 → 再执行 → 交付）在最底层冲突。** 标准的计划是固定物，而你的计划应该是**活的假设**，会随现实揭示而不断被推翻重修。

- **生产线模型**（行业在做，也是「长程自主」的方向）：计划 → 执行 → 交付。优化**推进**。
- **认识论模型**（你的模式）：决定 → 验证 → 重审。优化**理解**。

你审验一堆问题、让思考被触发，那正是**你的认知在产出的过程**，是对最终质量最重要的部分，不是可被优化的「等待时间」。当前 harness 把「人类的思考触发」当成链路里要消掉的延迟；而对你来说**那恰恰是价值本身**。

## 一个「认识论 harness」应该有的六件事

1. **决策优先而非文件优先**：你给「大目标」，它第一反应不是写代码，而是先摊开一个**结构化的决策空间**，让你先选方向。
2. **依据是一等公民**：每个计划步都承载「为什么选这个而不是那个」「考虑过哪些替代」。
3. **可逆、带检查点**：agent 的工作是一个**候选工作区**，能部分采纳、能回滚——不是一发不可收的 one-shot。
4. **审查是主界面，不是旁路功能**：让「审决策」而不是「审 diff」成为常态交互。
5. **架构记忆**：agent 始终装载**系统的决策史**（活的架构文档），不只是代码。捷径没有立足之地。
6. **活的计划**：计划是可被「现实证据」打击并触发的**假设**，重审计划是一等操作，不是认错重来。
