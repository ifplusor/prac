# Technical dock — pins, intent, running, active

> app 与实例见 [tech-app](./2026-11-05-tech-app.md)；窗口与焦点见 [tech-ui](./2026-11-05-tech-ui.md)；board 见 [tech-widget](./2026-11-05-tech-widget.md)。

## 1. 范围与不变量

**范围**：dock 上钉了哪些快捷方式、点击发生什么、unpin / restore 的语义。

dock 是**外壳表面**（像 activity bar），消费 app 与 board，不定义它们。

**不变量**

1. dock 只拥有 **pins**；running / active 是读来的，不是存的。
2. 一个 pin 是 **intent**：`appId` + `params`；不是实例句柄。
3. 但 pin **记住它自己启动的实例**（`instanceId`）——同一 `(appId, params)` 可以合法地有多个实例。
4. 其它入口启动的实例不归 dock 管。
5. unpin 不影响 board、widget、窗口；restore 只是把一条已有 board 重新 pin。
6. dock 只读窗口状态，从不写。

## 2. 数据模型

```ts
interface PracDockItem {
  readonly id: string;        // pin 的身份（通常是 board id）
  readonly appId: string;     // "prac.board"
  readonly label: string;
  readonly side: "left" | "right";
  readonly params?: unknown;  // 启动参数，core 不解释
  readonly instanceId?: string;  // 上次启动得到的实例
}

interface PracDock {
  list(): readonly PracDockItem[];
  pin(item: PracDockItem): void;
  unpin(id: string): void;
  subscribe(listener: () => void): () => void;
}
```

### 2.1 pin 的生命周期

| 事件 | `pins` | board / 窗口 |
| --- | --- | --- |
| `pin` | 加入 | 不变 |
| `unpin` | 移除 | **不变**（board 仍在，仍可由别处打开） |
| 关闭 board 窗口 | 不变 | 窗口关闭 |
| 实例退出 | 不变（`instanceId` 失效） | — |
| drag 到 dock | 加入 | 目标 board 接住 widget |

### 2.2 三种状态

| 状态 | 来源 | 用途 |
| --- | --- | --- |
| pinned | `PracDock.list()` | dock 是否显示 |
| running | `instances.get(pin.instanceId) !== undefined` | 运行指示 |
| active | WM 的焦点窗口属于该实例 | 高亮 |

## 3. 点击

```
click(pin)
  → instances.get(pin.instanceId)
      ├─ 命中 → activateWindow(instance.windows[0])       // reopen
      └─ 未命中 → applications.launch(pin.appId, pin.params)
                    → pin({ ...pin, instanceId: created.id })
```

- 命中时用 `activateWindow`，不再 `launch`——不新建实例；
- 未命中时 `launch` 按 app 的声明复用或新建；
- 若 `launch` 返回 `undefined`（app 未注册 / 启动失败），pin 保持不变。

## 4. 拖拽

| 落点 | 结果 |
| --- | --- |
| 已有 pin 的图标 | 打开该 board，把 widget move 进去 |
| dock 空白 | 新建 board window + move（提交时才创建，失败回滚） |
| 取消 | 删除本次新建的空 board |

hover 已有 pin 300–500ms 可激活该 board；hover 不改任何持久状态。

## 5. 持久化与恢复

- key：`prac-dock/v1`；
- 内容：pins（`id` / `appId` / `label` / `side` / `params` / `instanceId`）与顺序；
- `instanceId` 允许过期：读不到实例时视为未运行（heal），不删除 pin；
- 顺序即数组顺序；拖拽排序与 `side` 一起持久化。

## 6. 错误与测试

| 错误 | 触发 | 处理 |
| --- | --- | --- |
| `DUPLICATE_PIN` | 同 id 重复 pin | 覆盖（幂等） |
| `UNKNOWN_PIN` | `unpin` 不存在的 id | no-op |
| `DROP_OUTSIDE` | 拖到非落点 | cancel |

测试：点击已运行/未运行的 pin、unpin 后 board 仍在、restore、`instanceId` 过期后 heal、左右 side 的持久化。

## 7. Open

1. **overflow**：pin 很多时的滚动 / 分组；
2. **跨 Space**：dock 是全局还是 per-Space；
3. **dock 与 activity bar 是否同一表面**（当前左 dock 兼作 activity bar）；
4. **unpin 后的 restore 入口**：命令面板 / 右键菜单 / board 的 "Pin" 动作；
5. **pin 的 label 从哪来**：board 标题、widget 标题，还是用户可改。
