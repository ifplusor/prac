# Agent Note: 责任分配 — AI 有界认知 / 人意图·判断·校验 / harness 账本

## Problem

主流的隐含分工是「人 = 定目标 + 全程监督 + 判对错；AI = 稳定执行」，这让人和 AI 各自接到自己最不擅长的活：

- 用户被要求一次性、完整地说清意图，并在过程中持续盯一个比人类注意力快得多的过程。但人是靠**行动里逐步发现意图**的，不是靠先想清楚再动手。
- 模型被要求带稳定状态、长期自持地执行。但模型没有稳定状态——它是 next-token 预测器，不是带记忆的认知主体。让它「持续一个目标跑几小时、还能自我校验」，恰是它架构上最弱的一环。

## Proposal

- **AI 只负责有界认知**：感知当下、提出选项、生成、做局部转换。每个都是可验证的短单元，不做长期自持。
- **人负责意图 + 高杠杆处的判断 + 真实校验**，只在值得介入的决策点出现。
- **harness 负责账本**：维护外部、持久、可核实的事实账户，**不信任模型的自我报告**。
- **验证环**：产出 → harness 独立对现实校验（编译？测试？符合约定？）→ 通过才入账。错误分类：机械性（修完重试）、方向性（重审方案）、能力缺口（当作修的机会）。

## Alternatives considered

- **保持默认分工（人监督 + AI 执行）**：人当不了高速过程的监督者（注意力跟不上、会疲劳），AI 被要求做它最弱的自持执行。手感差的根源往往不是某个开关，而是这个交接边界没设计好。
- **「让 AI 长程自主、人只在最后验收」**：把责任甩出去在技术上太容易，造成责任真空——以为有验证，其实没人真在看，信任膨胀到远超实际核验。且与「边做边想」的工作方式冲突。
